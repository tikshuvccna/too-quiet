שקט מדי: גרסה להורדה (בלי צורך באינטרנט אחרי ההורדה)

1. חלץ את כל הקבצים מהקובץ המכווץ (לא להפעיל מתוך ה-ZIP).
2. לחץ פעמיים על start.bat. ייפתח חלון שחור ובעוד רגע הדפדפן יפתח את המשחק.
3. כשמסיימים לשחק, סוגרים את החלון השחור.

דרישה: Python או Node.js מותקנים במחשב (רוב מחשבי המורים מכילים אחד מהם).
אם אין, אפשר לשחק ישירות באתר: https://tikshuvccna.github.io/too-quiet/

ההתקדמות נשמרת בדפדפן. אם מחליפים דפדפן או מחשב, ההתקדמות לא עוברת.
