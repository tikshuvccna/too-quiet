# שקט מדי (Too Quiet)

משחק לימוד בדפדפן לתלמידי כיתה י״א, בנושא מבוא לרשתות תקשורת. עולם פתוח בזווית אלכסונית, פנטזיה ומסתורין: עמק שנראה מושלם, ומי שחותך בו את החוטים.

**זו דוגמית ראשונה לבדיקה**, לא המשחק המלא.

## מה יש בדוגמית
- כפר אחד, שלושה בתים שנכנסים אליהם, אוספים (כרטיסי חוט, דפי יומן, חפצים).
- שיעור 01 (מהי רשת, לקוח-שרת ועמית-לעמית) עם 8 סימולציות, שאלות הבנה, חידון ומשחקון בשלוש רמות.
- ראיית חוטים: הכוח של הדמות. מתקנים תקלות רק אחרי שלומדים.
- תקרת 10 דקות בעולם הפתוח, אחריה סערת חוטים שמטלפרת לשיעור.

## הרצה
```
npm install
npm run dev       # פיתוח
npm test          # בדיקות
npm run build     # בנייה ל-dist
```
פרמטרים לבדיקה: `?fresh` (שמירה חדשה), `?cap=60` (תקרת סשן בשניות).

## אמנות
דמויות ובתים מרונדרים ב-Blender (סקריפטים ב-`art/`), לפי כללי צניעות: שרוולים ארוכים, שמלות עד הקרסול, כיסוי ראש. ראו `art/README.md`.
